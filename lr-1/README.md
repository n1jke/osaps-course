# Лабораторная работа №1 — вариант 26 «Process против Thread»

Цель работы — сравнить процессы и потоки Windows на одной вычислительной задаче. Программа считает сумму для диапазона `1..N` последовательно, `K` потоками и `K` дочерними процессами; затем сравнивает результаты и измеряет полное время и время создания исполнителей. Для процессов частичные суммы передаются через временные файлы, для потоков — через общую память процесса.

## Сборка на Windows

Нужны Visual Studio с компонентом **Desktop development with C++** и CMake. В обычной Windows x64 открой «Developer Command Prompt for VS» и выполни:

```bat
cd lr-1
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
cd build\Release
```

`main.exe` и `worker.exe` должны лежать в одном каталоге.

## Запуск

```bat
main.exe <N> <K>
```

`N` — число, кратное 8, от 8 до 3 000 000; `K` — 1, 2, 4 или 8. Например:

```bat
main.exe 3000000 4
```

Для проверки только последовательного расчёта:

```bat
main.exe 8 1 seq
```

Успешный обычный запуск выводит `matches sequential=yes` и для потоков, и для процессов; коды завершения должны быть `0`.

## Эксперимент

Требование задания: для `K = 1, 2, 4, 8` выполнить не менее трёх запусков с одинаковым `N`, то есть минимум 12 обычных запусков. В `cmd.exe` их можно запустить одной командой:

```bat
for %K in (1 2 4 8) do @for /L %R in (1,1,3) do @main.exe 3000000 %K
```

В отчёт занеси для каждого `K` среднее или медиану полного времени потоков и процессов, их времени создания, а также сравнение используемых ресурсов и способа получения общего результата.
