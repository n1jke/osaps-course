# Сборка отчёта

Отчёт — черновик: перед сдачей заполните титульный лист, приложение об ИИ, данные, результаты и выводы; проверьте текст по фактическим запускам. Ссылки на репозиторий предоставляются через LMS.

Нужны Typst и шрифты из `bsuir_typst/README.md`, в частности Times New Roman, Courier New, TeX Gyre Termes Math и XITS Math. Шаблон `bsuir_typst` должен находиться рядом с `lr-4` в корне репозитория. Это отдельный вложенный Git-репозиторий: обеспечьте его наличие на компьютере сборки.

## Установка на Windows

Установите Git для Windows, если он ещё не установлен. В PowerShell выполните:

```powershell
winget install --id Typst.Typst --exact
```

Закройте и откройте PowerShell, затем проверьте:

```powershell
git --version
typst --version
```

Если `winget` недоступен, скачайте архив Windows с [официальной страницы Typst](https://typst.app/open-source/) и добавьте каталог с `typst.exe` в `PATH`.

Перейдите в каталог, где хотите разместить лабораторные, и клонируйте свой репозиторий. Вместо адреса ниже подставьте реальный адрес своего репозитория:

```powershell
git clone <адрес-своего-репозитория> osasp-course
cd osasp-course
```

В PowerShell вместо `<адрес-своего-репозитория>` нужно указать действительный URL без угловых скобок. Если репозиторий уже находится на компьютере, переходите сразу в его корневую папку и повторно его не клонируйте.

Если папки `bsuir_typst` в корне ещё нет, клонируйте шаблон и выберите версию, которая использовалась при подготовке отчёта:

```powershell
git clone https://github.com/artemious3/bsuir_typst.git bsuir_typst
git -C bsuir_typst checkout b9e186318f94191086e919e624a1e710bf5db0f7
```

Установите шрифты, перечисленные в `bsuir_typst/README.md`. Проверить доступность шрифтов можно так:

```powershell
typst fonts | Select-String 'Times New Roman|Courier New|TeX Gyre Termes Math|XITS Math'
```

Если необходимые шрифты отсутствуют, установите их и повторите проверку. После клонирования должны также присутствовать все файлы отчёта, исходники лабораторной, скрипт графиков и нужные изображения — если они ещё не закоммичены и не отправлены в репозиторий, перенесите их на Windows отдельно.

## Сборка

Графики находятся в `lr-4/report-assets/`, CSV — в `lr-4/test-results/`. В `ratio.csv` некоторые средние ожидания писателей не совпадают с суммой ожидания и числом операций. Перед сдачей восстановите и проверьте исходные данные, затем перестройте графики:

```powershell
py -m pip install matplotlib
py lr-4/scripts/plot_results.py --ratio lr-4/test-results/ratio.csv --duration lr-4/test-results/read-duration.csv --output-dir lr-4/report-assets
```

Эта команда перезапишет два графика в `report-assets`; диаграмму `interaction.png` она не меняет.

В PowerShell из корня репозитория:

```powershell
typst compile --root . lr-4/report.typ lr-4/report.pdf
```

Команда собирает черновик с местами под изображения. Чтобы включить все три изображения, сначала поместите PNG в `lr-4/report-assets/` под именами из README этого каталога, затем выполните:

```powershell
typst compile --root . --input figures=yes lr-4/report.typ lr-4/report.pdf
```

Сборка с `figures=yes` требует наличия диаграммы и двух изображений по путям, указанным в `report.typ`. Два графика необходимо строить только по реальным данным. Листинги приложения и генератора графиков читаются непосредственно из файлов проекта при сборке, поэтому файлы `lr-4/src/`, `lr-4/scripts/plot_results.py` и `lr-4/readers-writers.md` должны присутствовать. Для финальной версии дополните отчёт реальными CSV, скриншотами проверок и анализом. Проверьте PDF визуально после сборки.
